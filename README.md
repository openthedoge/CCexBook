# CC练习本（CCexbook）

一个**纯离线、零权限**的 Android 刷题 App：支持导入 Excel / Word / 文本题库，顺序刷题、错题本、模拟考试、标记与笔记、数据备份，并可为每道题写笔记。

> 本项目基于 **紫若灵刷题练习 v1.13.0**（原作者：**lssudi**）二创而来，遵循原作者的开放态度做了大量功能增补与重构。原版功能版权归原作者，本仓库仅包含 fork 后的修改。

---

## 特性

### 题库导入
- 支持 **xlsx / docx / txt / csv** 四种格式
- Word 表格可直接在内嵌图片时导入，图片自动提取并随题显示
- 导入前可预览、识别题型、批量或逐条指定题型
- 内置 Word / Excel 导入模板（应用内可生成、导出）

### 刷题
- 题型：单选、多选、判断、填空、简答、排序、其它
- 模式：顺序练习、随机刷题、背题模式、专项练习、错题重练、收藏练习、模拟考试
- **继续刷题**：直接接上次进度，不用每次重新选
- **自定义起始题号**：只接受数字，超出范围自动定位到第一题 / 最后一题
- 答题卡：区分「本次已答」与「历史已答」，自动定位当前题
- 选项顺序可随机；答对可自动下一题；可开关震动与音效

### 题目管理
- **追加题目**：往现有题库里插题，支持文件或直接粘贴文本；可按分类自动插入，也可逐题确认后指定位置
- **移动题目**：编辑器里可把某题移到任意分类的任意位置
- **删除题目**：在「浏览全部题目」中长按，删除后题序自动前移
- **重置题库**：首页长按题库，可勾选清空做题记录 / 错题本 / 标记 / 收藏（总统计不受影响）
- 题干、选项、答案、解析、图片、分类均可编辑

### 标记与笔记
- **多词条标记**：每个题库独立一套词条（最多 10 个），题目可同时打多个；内置「其他」不可删改；支持「设为默认 / 重命名 / 删除」
- 题库内可按**词条多选**筛选，并与题型、分类筛选叠加
- **笔记**：做完题目后，解析下方出现笔记区，点击即可为当前题写笔记（取消 / 保存）；笔记跟题走，删除题目或题库即消失

### 统计
- 首页与统计页：累计做题、正确率、今日做题、连续打卡、近 7 日柱状图、各题型正确率、各题库进度
- **总统计为独立账本**：删除题库、清空练习记录都不会清零，只有设置里的「清空统计」（二次确认）能归零

### 导出与备份
- 导出 **Excel**（不含图）或 **Word 表格**（图片内嵌，可改文字后再导入回题库）
- 导出**试卷**（Word，按题型分组，可附答案解析），图片内嵌
- **整库备份 / 恢复**：数据库 + 图片打包为 zip
- 恢复支持「追加导入」与「覆盖替换」；覆盖前自动留存「原数据快照」
- 兼容旧版本备份：打开时自动迁移（旧标记自动转为「疑错」词条）

### 外观
- 主题：跟随系统 / 浅色 / 深色 / 纯黑（AMOLED）
- 5 种主题配色：科技蓝、中国红、翡翠绿、活力橙、浪漫紫
- 字体大小：小 / 标准 / 大 / 特大

## 数据与隐私

- **无任何权限**，不联网、不收集数据
- 所有数据保存在本机：SQLite 数据库 + 应用私有目录中的图片
- 卸载即删除全部数据（请自行备份）

环境要求：

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Gradle | 8.7（仓库自带 wrapper） |
| Android Gradle Plugin | 8.5.2 |
| compileSdk / targetSdk | 34 |

```bash
./gradlew assembleDebug      # 调试包
./gradlew assembleRelease    # 正式包
./gradlew testDebugUnitTest  # 单元测试（Robolectric，180+ 用例）
```


应用包名为 `com.ziruoling.quiz.c`，可与原版 `com.ziruoling.quiz` 共存安装。

## 题库格式

导入表格为 11 列，列序固定：

| 题型 | 题目 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 答案 | 解析 | 分类 |
|---|---|---|---|---|---|---|---|---|---|---|

- 题型：单选题 / 多选题 / 判断题 / 填空题 / 简答题 / 排序题 / 其它题
- 判断题答案：对 / 错 / √ / × / A / B 均可
- 多选题答案如 `ABD`；排序题答案填正确顺序字母串（如 `CAB`）
- 填空多个参考答案用 `||` 分隔
- 题干开头的序号（如 `5.`）会被识别为「原题号」，在练习页以角标显示，导出时写回行首
- 图片直接插入「题目」单元格即可

文本、CSV 格式同理，一行一题。

## 已知限制

- **多语言未完成**：当前界面固定中文；英文资源与翻译框架已预留（见 `开发备注-多语言方案.md`）
- 笔记不参与搜索与导出，仅随题保存与备份
- 排序题、简答题不参与自动判分
- 导出的 Excel 不含图片（需要图片请导出 Word 或整库备份）
