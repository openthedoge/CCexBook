# 更新日志（最新在上，格式：## 版本  日期，条目以 - 开头）

## v1.6.0  2026-11-21
- 新增：一些BUG
- 新增：刷题界面解析下方新增笔记（注意：笔记仅跟随题目与存档，无法导出，任何删除题目的操作均会导致笔记消失）
- 改进：整体界面优化
- 修复：词条功能的逻辑相关修复
- 修复：追加导入旧版本备份时，原有的「疑错」标记丢失

## v1.5.0  2026-11-21
- 新增：更多BUG。
- 新增：标记改为多词条体系（长按标记触发，自行体验）
- 改进：优化题库查询与图片显示
- 改进：重构部分代码，提高维护性
- 修复：导入旧版本备份时，一些兼容性问题

## v1.4.0  2026-11-21
- 因修改部分过多，重新标准下应用名与版本号
- 新增：首页长按题库「追加题目」——支持选文件或直接粘贴文本；可自动按分类追加，也可逐题确认（编辑后指定分类与位置）
- 新增：题目编辑器底部「移动到其他分类…」，可插到目标分类的任意位置（默认末尾）
- 新增：首页长按题库「重置题库」——可勾选清空做题记录（含进度）/错题本/标记/收藏，需二次确认；总统计不受影响
- 新增：浏览全部题目时，长按题目可「编辑题目 / 删除题目」，删除后题序自动前移
- 改进：标记改为多词条——每个题库最多 10 个词条，默认「其他」不可删除但可改名；题目可同时打多个词条；题库内可按词条多选筛选（与题型筛选叠加）
- 改进：设置改为分组入口——外观 / 刷题行为 / 数据管理 / 重置选项 / 关于
- 改进：应用名改为「CC练习本」，版本号改为 1.4.0
- 移除：题库页「重置进度」入口（顺序练习里可直接重新开始）
- 移除：首页长按题库的「导出题库」入口（题库页已保留导出表格 / 导出文档）
- 说明：多语言（英文）翻译工作正在进行中，本版界面固定中文

## fork-v1.3  2026-11-21
- 新增：题库首页「继续刷题」，直接按上次进度续上，不用再进「顺序练习」选二级菜单
- 新增：顺序练习支持「自定义起始题号」，只收数字，超出范围自动定位到第 1 题或最后一题
- 新增：题库导出支持 Word 文档（表格版，图片内嵌，可改文字后再导入回题库）
- 新增：识别题干开头的原题号（按篇/节重新计数），在题干前用小标签显示；没有序号时自动按「分类」编号（分类变即从 1 重数），导出时写回行首
- 改进：导出统一为二级菜单（导出表格 / 导出文档），首页与题库页行为一致
- 修复：导出试卷（Word）不带图，现已把题目图片内嵌到卷面，后台生成不卡界面
- 修复：删除题库或清空练习记录会连带清零首页累计统计；总统计改为独立保存，只有设置里的「清空统计」（二次确认）能归零
- 修复：题目、选项里的上标/下标显示不全（如 2⁴ 的 4 只露一半）
- 修复：首页长按题库，「导出」菜单点击无反应（菜单文案与判断不一致）

## fork-v1.2  2026-11-21
- 分享菜单由两项扩为四项：分享题目 / 分享题目 + 答案与解析 / 复制题目 / 复制题目 + 答案与解析
- 题型固定为 单选 / 多选 / 判断 / 填空 / 简答 / 排序 / 其它，取消「看图题」（图片与题型无关）
- 导入时题型无法识别会提示「统一指定」或「逐条指定」
- 答题卡打开时自动定位到当前题
- 修复：题型正确率把「正确数」与「总数」算反，可能导致超过 100%、全错题型不显示
- 修复：题目浏览页题型筛选错位（点多选显示单选等）
- 修复：关闭「答对自动移出错题本」后仍会自动移出，且「移出错题本」按钮不出现
- 修复：纯黑（AMOLED）主题下「疑错」按钮文字与底色都过暗
- 修复：关于页对长按操作的描述不准确
